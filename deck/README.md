# AI Can Build It: interactive talk deck

`index.html` is a single self-contained slide deck for the "AI Can Build It" talk. It is deployed as its own static Vercel project (Root Directory `deck`, Framework Preset "Other", no build command) so that it is not subject to the FlashFlip app's strict Content-Security-Policy.

Open `index.html` directly in a browser to use it locally. It needs an internet connection for the QR-code library.
